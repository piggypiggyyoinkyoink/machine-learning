# Machine Learning
This repository contains code for a baseline and improved version of a hybrid transfer/ensemble machine learning approach to classifying objects from the [**ThingsEEG-Text**](https://figshare.com/ndownloader/files/36977293) dataset, implemented using scikit-learn in Python. The baseline uses simple parameter averaging whereas the improvement uses a custom class weighted voting ensemble classifier `cwvclassifer.py`. Hyperparameters were tuned via Leave-One-Subject-Out cross-validation.

See `report.pdf` for full paradigm and technical details. Note: the images are small due to the report page length limit.
